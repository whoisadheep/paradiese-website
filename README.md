# Paradiese — Sundry Crunchy

> **Taste Never Ends** — Thoughtfully dehydrated natural ingredients and spice powders that bring flavour, colour, and aroma to everyday cooking.

A modern, responsive brand website built with React 19, Vite, and Tailwind CSS.

## 🌿 Features

- **Interactive Brand Experience**: Immersive landing page showcasing dehydrated natural ingredients and spice blends.
- **Product Showcase & Modal Details**: Interactive product catalog with detailed culinary usage, nutrition, and packaging insights.
- **Brand Story & Quality Assurance**: Highlighting farm-to-table natural dehydration processes.
- **Culinary Inspiration**: Recipe ideas and creative uses for dehydrated vegetables and spices.
- **Mobile Responsive & High Performance**: Optimized assets (WebP/JPEG), preloaded critical above-the-fold content, and fluid layouts.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Linting**: [Oxlint](https://oxc.rs/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/whoisadheep/paradiese-website.git
cd paradiese-website

# Install dependencies
npm install

# Start local development server
npm run dev
```

The site will be available at `http://localhost:5173`.

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```

## ☁️ Deployment

This project is optimized for deployment on [Vercel](https://vercel.com):

1. Push this repository to GitHub.
2. In Vercel, select **Add New Project** and import `paradiese-website`.
3. Vercel automatically detects Vite with:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
